# ss🏗️ 전체적인 시스템 구조 (동작 원리)
내가 컴퓨터를 켜지 않아도 메일이 오는 이유는, 깃허브가 제공하는 '클라우드 가상 컴퓨터'가 나 대신 매일 지정된 시간에 깨어나서 일을 하기 때문입니다.

[ 1. 깃허브 타이머 ] ⏰ 아침 6시! 가상 컴퓨터 깨우기
        ↓
[ 2. 가상 컴퓨터 세팅 ] 💻 파이썬 설치 + 코드 및 라이브러리 다운로드
        ↓
[ 3. 안전 금고 연결 ] 🔑 Secrets에서 네이버 Key & 구글 앱 비밀번호 가져오기
        ↓
[ 4. 정보 수집 ] 🌐 네이버 API를 통해 어제 자 개발 뉴스 긁어오기
        ↓
[ 5. 메일 발송 ] ✉️ 구글 우체부(SMTP)를 통해 내 네이트 메일로 리포트 전송
① ⏰ 1단계: 깃허브 타이머가 가상 컴퓨터를 깨움 (deploy.yml)
우리가 마지막에 수정했던 deploy.yml 파일은 깃허브에게 내리는 '스케줄 명령서'입니다.

파일 상단에 적힌 cron: '0 21 * * *'이라는 문구가 핵심입니다. 깃허브 시스템은 영국 시간(세계 표준시)을 기준으로 작동하기 때문에, 한국 시간 아침 6시에 맞추기 위해 영국 시간 밤 9시(21시)로 타이머를 맞춰둔 것입니다.

아침 6시 정각이 되면 깃허브의 알람이 울리면서, 우리 프로그램을 실행해 줄 아무도 쓰지 않는 깨끗한 리눅스(Ubuntu) 가상 컴퓨터 한 대를 깃허브가 무료로 대여해 줍니다.

② 💻 2단계: 일할 준비하기 (코드와 도구 세팅)
처음 켜진 가상 컴퓨터는 아무것도 없는 백지 상태입니다. 명령서(deploy.yml)에 적힌 순서대로 가상 컴퓨터가 빠르게 세팅을 시작합니다.

코드 가져오기: 내가 저장소에 올려둔 development_news_mailer.py 파일을 가상 컴퓨터 안으로 다운로드합니다.

파이썬 설치: 프로그램을 실행할 수 있도록 파이썬 환경을 구축합니다.

부품 추가 (requirements.txt): 인터넷에서 뉴스를 긁어올 때 필요한 외부 부품들(requests 등)을 명령서에 따라 자동으로 다운로드하여 가상 컴퓨터에 설치합니다.

③ 🔑 3단계: 안전 금고(Secrets)에서 비밀번호 꺼내기
컴퓨터가 일할 준비를 마쳤으면 이제 네이버 검색창과 구글 메일 서버에 로그인해야 합니다. 이때 보안이 아주 중요합니다.

코딩 창에 아이디와 비밀번호를 그대로 노출해 두면 전 세계 누구나 내 비밀번호를 볼 수 있게 됩니다.

이를 막기 위해 우리는 깃허브의 안전 금고(Settings > Secrets)에 비밀번호들을 숨겨두었습니다.

가상 컴퓨터는 프로그램이 딱 실행되는 순간에만 이 금고에 접근해 SMTP_PASSWORD와 네이버 키 값을 몰래 꺼내와 메모리(환경 변수)에 올려두고 사용합니다. 프로그램이 종료되면 이 값들은 흔적도 없이 사라집니다.

④ 🌐 4단계: 네이버 API를 통해 뉴스 수집 (development_news_mailer.py)
이제 메인 프로그램인 파이썬 코드가 작동합니다.

코드 내부에 지정해 둔 8가지 키워드("도로 개발", "토지 개발" 등)를 가지고 네이버 뉴스 검색 API 서버에 문을 두드립니다.

이때 금고에서 꺼내온 네이버 Client ID와 Secret 값을 함께 제시하여 "나 허가받은 사용자야"라고 인증을 받습니다.

네이버는 인증이 확인되면 어제 날짜로 보도된 관련 뉴스 데이터들을 깔끔한 텍스트 묶음(JSON 형태)으로 파이썬 프로그램에게 건네줍니다.

파이썬 프로그램은 이 수많은 뉴스 중에서 언론사, 링크, 요약문 등을 보기 좋게 정렬하여 하나의 '뉴스 리포트 본문(텍스트)'으로 조립합니다.

⑤ ✉️ 5단계: 구글 우체부(SMTP)를 통한 메일 발송
마지막으로 조립된 리포트를 메일로 보낼 차례입니다. 메일을 보낼 때는 SMTP(Simple Mail Transfer Protocol)라는 인터넷 국제 우편 규약을 사용합니다.

파이썬 프로그램이 구글의 메일 발송 서버(smtp.gmail.com)에 접속합니다.

이때 우리가 발급받았던 16자리 구글 앱 비밀번호를 사용해 구글 메일 서버에 로그인합니다.

처음 시도했던 네이트 메일 서버는 해외 클라우드(깃허브)에서 접속하는 것을 '해킹 시도'로 판단해 차단(Your IP is blocked)했었지만, 구글 메일 서버는 우리가 직접 발급한 일회용 앱 비밀번호를 제시했기 때문에 안전한 접근으로 인정하고 문을 열어줍니다.

로그인에 성공하면 구글 메일 서버가 우체부가 되어, 지정된 최종 수신처인 내 네이트 메일함(civillss@nate.com)으로 뉴스 리포트를 슝 날려줍니다.

💡 요약하자면
이 모든 과정이 매일 아침 6시 정각에 시작되어 단 20~30초 만에 일어납니다. 가상 컴퓨터는 메일을 성공적으로 발송하고 나면 Sent report라는 일기(로그)를 한 줄 남긴 뒤, 스스로 포맷되어 세상에서 사라집니다.

선생님께서는 컴퓨터를 켜두실 필요도 없고, 깃허브 사이트에 들어와 계실 필요도 없습니다. 깃허브라는 거대한 클라우드 시스템이 매일 아침 알아서 비서를 고용해 일을 시키고 퇴근시키는 완벽한 무인 자동화 공장을 돌리고 계신 셈입니다.
